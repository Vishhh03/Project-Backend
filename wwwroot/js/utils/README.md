# Utils Directory

This directory will contain utility functions and helper classes for the FinalDestination frontend application.

## Planned Utilities

The following utilities will be implemented in future tasks:

### Core Utilities (Task 2)
- **api-client.js** (Task 2.1) - HTTP client wrapper for API communication
- **router.js** (Task 2.2) - SPA routing system
- **storage-service.js** (Task 2.3) - localStorage/sessionStorage wrapper

### Validation Utilities (Task 11.3)
- **validator.js** - Form validation framework
- **validation-rules.js** - Custom validation rules

### Helper Utilities
- **helpers.js** - General utility functions
- **date-utils.js** - Date formatting and manipulation
- **currency-utils.js** - Currency formatting
- **string-utils.js** - String manipulation helpers

### Event System
- **event-bus.js** - Component communication system

## Architecture

Utilities are designed to be:
- Pure functions where possible
- Stateless and reusable
- Well-documented with JSDoc
- Thoroughly tested
- Framework-agnostic for future Angular migration

## Usage

Utilities will be imported and used by services and components as needed. They provide common functionality that can be shared across the application.
